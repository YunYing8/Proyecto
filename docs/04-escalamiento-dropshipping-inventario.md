# Estrategia de Escalamiento: Dropshipping a Inventario Propio

## Roadmap de Escalamiento

### Fase 1: Validacion con Dropshipping (Meses 1-3)

**Objetivo:** Validar productos, mercado y marca con inversion minima.

**Operacion:**
- Proveedor: AliExpress / CJ Dropshipping / Zendrop
- Fulfillment: Directo desde proveedor a cliente
- Envio: ePacket o linea especial (10-20 dias)
- Catalogo: 20-30 productos curados

**Metricas clave:**
| Metrica | Objetivo |
|---------|----------|
| Tasa de conversion | > 1.5% |
| Costo de adquisicion (CAC) | < S/ 25 |
| Ticket promedio | > S/ 120 |
| Margen bruto | > 40% |
| Tasa de devolucion | < 5% |
| NPS | > 40 |

**Acciones:**
- Lanzar con 20-30 SKUs seleccionados
- Testear 5-10 productos en ads simultaneamente
- Identificar top 10 productos ganadores (mejor conversion + margen)
- Recopilar feedback real de clientes peruanos
- Construir base de datos de clientes y email list
- Iterar sobre precios, copy y creativos

**Inversion estimada:**
| Concepto | Monto mensual |
|----------|--------------|
| Shopify + apps | S/ 200 |
| Dominio + email | S/ 50 |
| Ads (FB/IG/Google) | S/ 2,000-5,000 |
| WhatsApp Business | S/ 0 (gratis) |
| Herramientas (Canva, etc.) | S/ 100 |
| **Total** | **S/ 2,350-5,350** |

---

### Fase 2: Stock Local Bestsellers (Meses 3-6)

**Objetivo:** Reducir tiempos de entrega para los productos mas vendidos.

**Operacion:**
- Importar top 10-15 productos por volumen desde proveedor
- Almacen: Mini bodega en Lima o fulfillment tercerizado
- Envio Lima: 24-48h (Olva Courier, Shalom)
- Envio provincias: 3-5 dias
- Mantener dropshipping para long tail de catalogo

**Proveedor directo:**
- Contactar fabricantes en 1688.com (version B2B de AliExpress)
- Negociar MOQ (cantidad minima) de 50-100 unidades
- Solicitar precio FOB (sin intermediarios)
- Importar via courier (DHL, FedEx) para lotes pequenos
- Importar via maritimo para lotes grandes (> 500 unidades)

**Logistica local:**
| Opcion | Pros | Contras |
|--------|------|---------|
| Mini bodega propia | Control total | Costo fijo, gestion |
| Fulfillment 3PL | Escalable, sin gestion | Costo por pedido, menos control |
| Hibrido | Flexibilidad | Complejidad |

**Recomendacion:** Empezar con fulfillment 3PL (Chazki, FullCommerce Peru) y migrar a bodega propia cuando el volumen lo justifique (> 200 pedidos/mes).

**Inversion adicional:**
| Concepto | Monto |
|----------|-------|
| Stock inicial (top 10 productos) | S/ 10,000-20,000 |
| Fulfillment 3PL (setup) | S/ 500 |
| Importacion + aduanas | S/ 3,000-5,000 |
| Empaque con marca | S/ 1,500 |

---

### Fase 3: Catalogo Propio + Marca (Meses 6-12)

**Objetivo:** 80% productos con stock local, marca reconocible.

**Operacion:**
- 50-80 SKUs con stock permanente
- Importacion directa de fabricas (1688, ferias Canton)
- Almacen propio o 3PL dedicado
- Envio express como estandar
- Dropshipping solo para productos de prueba

**Acciones:**
- Negociar con 3-5 fabricantes directos
- Desarrollar empaque propio (caja con marca TecNova)
- Incluir material de marca: sticker, tarjeta de agradecimiento, manual en espanol
- Crear bundle de productos (ej: "Kit Home Security TecNova")
- Implementar programa de fidelizacion

**Empaque propio (especificaciones):**
```
Caja exterior: Carton corrugado blanco con logo TecNova
Interior: Foam protector negro
Incluido:
  - Tarjeta de agradecimiento personalizada
  - Sticker TecNova
  - Guia rapida en espanol
  - Tarjeta de garantia con QR
  - Codigo de descuento para siguiente compra
```

---

### Fase 4: Marca Propia (White Label) (Meses 12+)

**Objetivo:** Productos exclusivos bajo marca TecNova.

**Operacion:**
- Seleccionar 5-10 productos para white label
- Negociar con fabricas OEM en China
- Customizar: logo, empaque, manual, certificaciones
- Registrar marca en INDECOPI

**Criterios para white label:**
- Producto con > 100 ventas mensuales
- Margen > 50%
- Baja complejidad tecnica (menos soporte)
- Alta demanda comprobada

**Ejemplo de producto white label:**
```
Producto: Audifonos TWS Bluetooth 5.3
Costo OEM: $5-8 USD
Customizacion: Logo TecNova en case y audifonos
Empaque: Caja premium con branding
Precio venta: S/ 129
Margen: ~65%
```

## Metricas de Decision para Escalar

### Cuando pasar de Fase 1 a Fase 2:
- [ ] > 100 pedidos/mes consistentes
- [ ] Top 10 productos identificados
- [ ] Margen bruto > 40%
- [ ] Flujo de caja positivo por 2 meses seguidos
- [ ] Tasa de devolucion < 5%

### Cuando pasar de Fase 2 a Fase 3:
- [ ] > 300 pedidos/mes
- [ ] Relacion directa con al menos 3 fabricantes
- [ ] Capital para importar lotes de > 500 unidades
- [ ] Proceso de importacion validado (2+ importaciones exitosas)
- [ ] Marca reconocida (> 1000 seguidores en redes)

### Cuando pasar de Fase 3 a Fase 4:
- [ ] > 500 pedidos/mes
- [ ] Marca registrada en INDECOPI
- [ ] Relacion con fabrica OEM establecida
- [ ] Capital para MOQ de white label (tipicamente 500-1000 unidades)
- [ ] Equipo de al menos 3 personas
